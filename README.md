 ## 写这个项目的初衷
 
 期末很多专业课老师不划重点，复习范围又广。有社交的同学能找学长学姐问重点，i人只能面对网上的碎片信息。
 
 所以这个项目的初衷是**让信息平权，让知识共享**。
 
 每个课程的 README 都尽量写清楚：怎么学、重点在哪、避坑建议。
