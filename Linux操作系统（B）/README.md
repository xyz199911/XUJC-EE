## 怎么读这些文件

每份文档第 2 页是「审校与修订说明」。正文按原文逐页排，改动处标〔已修订〕，截图下方是四类批注：

- 〔已修订〕原文写错了，已按正确做法改写，旁边给了依据；
- 〔需补答〕原文缺文字结论，已补写，可按自己的话再改；
- 〔需重做〕截图或实验本身不成立（命令报错、贴字冒充截图、用的别人机器、题目没做完），要自己重做重截；
- 〔提示〕补充说明，不影响判分。

PDF 是同内容的只读版，DOCX 可以直接改。

## 各章查出来的主要问题

### 第 1 章 基本命令

- 实验内容表把 `cd` 写成「切换用户」，实际是切换目录，切换用户用 `su`；
- 第 6 题要求主目录下建 `test1`、在 `test` 里建 `file1.txt`，截图多建了一个 `test` 目录，`file1.txt` 也建在 `test1` 里；
- 第 7 题要删的是 `test1` 里的 `file1.txt` 和 `test` 目录，截图删成了 `test1`；
- 第 8 题只贴了 `ls`、`ll` 两张图，没写「差别」的结论；
- 第 9 题 `su` 顺序与题目相反；子项目二的重定向截图是手打贴字，没有命令提示符，顺序也错乱；
- 封面缺「学院」，班级写法前后出现 4 种；第 3 题截图里多了手打的 `# 查看file1.txt`；
- 「四、实验中的问题和解决方法」全空。

### 第 3 章 用户和组管理

- 第 2 题 `usermod -e 2025/12/31` 日期格式错（man 里是 YYYY-MM-DD），而且日期早于做实验的时间，账号建完就是过期状态，直接导致第 4 题 `su tom` 报 `Your account has expired`；
- 第 3 题锁定用户没成功，截图报 `Usage: usermod [options] LOGIN`（选项敲成了小写 `-l`），证据是紧接着 `su jack` 直接进去；
- 第 4 题缺 `id` 输出（看不到 UID/GID）；阶段 2 的 `useradd` 是无提示符的贴字，同一张图里 `groupadd` 重复出现且没有 `already exists`，是拼接的；
- `gpasswd -d Tim software` 报 not a member、`groupdel classone` 报 `cannot remove the primary group of user 'Allen'`，都是主组和附加组的差别，报告一句没解释；
- `gpasswd software` 停在等输入处，是半截命令；
- 第 5 题 `useradd Tom`（大写）和 `adduser tom`（小写）被当成同一个用户；题目问「组 Tom 为什么不存在」，报告没答（`USERGROUPS_ENAB=yes` 时 `userdel` 会顺带删掉无成员的私有组）。

### 第 4 章 文件系统

- 实验目的整段抄第 3 章（还在说「组和组管理」）；
- `chmod -R 777 /home` 过度授权，题目只要求 `chmod 777 /home`，截图里 `/home/test` 下所有文件都变成了 777；
- c) 题要求切到 john 建 `file1.txt`，截图提示符是 root，`file1.txt` 属主是 `root:root`，根本没切用户；另外用 `ll` 列了整个目录，没做到「只截所需」；
- e)、f) 题在 root 身份下加 `sudo` 多余；`adduser tom` 同一段贴了两张重复图；
- 「四、实验中的问题和解决方法」全空。

### 第 5 章 系统管理

- 第 5、6 题截图的提示符是 `xujc@`（别人的学号），不是本人机器，这在查重时是硬证据；
- `df` 里 sdb1 是 9.8G，第 7 页又写 974M，两次不是同一次实验；
- 添加硬盘只有 `mount`，没有 `fdisk`/`mkfs` 过程；`mount` 还报了 `already mounted`；
- `top` 没有体现「按内存排序」，要 `top -o %MEM` 或进去按 Shift+M；
- 附加题完全没做，第 7 页那张 `tree` 是别人的示例；`fstab` 那一行没贴出来；
- `netstat` 在新版 Ubuntu 要装 net-tools，日常用 `ss`；`ifconfig` 截了 5 个接口，太长。

### 第 7 章 Shell 编程

- `5.sh` 的 `ret=$(echo "scale=2; $a*$b/12 | bc)` 少一个双引号，三次运行全失败；
- `2.sh` 三次运行都报 `unexpected EOF while looking for matching '"'`，最后 `cat` 出来的脚本却是正常的，截图前后对不上；
- `3.sh` 没 `chmod +x`，输出写成 `1+2+...+15`，应写 `1+2+...+$n = $sum`；
- `1.sh` 的 `#! /bin/bash` 中间多了空格，没有参数个数校验，`cp` 后再 `rm` 应直接 `mv`；
- `6.sh` 逻辑对，但 `$sum` 没加引号；
- 「四、实验中的问题和解决方法」全空。
